# Security Policy

Security is a top priority for December. Responsible disclosure of security vulnerabilities helps keep the project safe for everyone.

Where to Report:

- **Private Security Advisory**: [Create a Security Advisory](https://github.com/phasehumans/december/security/advisories/new)
- **Email**: team@trydecember.com
- Do not report security vulnerabilities in public GitHub issues

What to Include:

- Description of the vulnerability and its impact
- Clear steps or code to reproduce the issue
- Affected components or packages

Reports will be acknowledged within 48 hours, followed by regular updates until a fix is released.
