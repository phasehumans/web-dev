# Primary-Source Audit: File Editing & Git-Diff Display Architecture

## Executive Summary

This audit examines how file modifications (modified vs newly created files) are processed, formatted, and rendered across the December codebase (`packages/tools`, `packages/tui`, `apps/cli`, and `apps/web`).

**Key Finding:**
Git-diff style blocks (`diff`, `+`/`-` line formatting) are **not generated by backend tool execution**. The FS tools in `packages/tools` (`edit_file`, `edit_diff`, `write_file`) execute file writes and return plain text confirmation messages (e.g. `"Successfully edited file: ..."`). Instead, the Terminal UI (`packages/tui`) **synthesizes pseudo-diff output client-side** by intercepting completed tool call inputs in `bot-message.tsx` and parsing `targetContent`/`replacementContent`, `ReplacementChunks`, `diff`, or `codeContent` into `+`/`-` lines.

## 2. Terminal UI Layer Audit (`packages/tui`)

The Terminal UI parses tool input arguments to construct and style synthetic git-diff outputs inside command execution blocks.

### 2.1 Synthetic Diff Block Construction in `BotMessage`

- **Location:** [`packages/tui/src/components/messages/bot-message.tsx:L304-L375`](file:///home/chaitanya/code/december/packages/tui/src/components/messages/bot-message.tsx#L304-L375)
- **Mechanism:** When a tool block completes (`block.type === 'command'` and `!isRunning`), `bot-message.tsx` inspects `block.toolName` and `block.toolInput` (JSON string of input parameters) to compute `displayOutput`:

```typescript
// bot-message.tsx lines 313-374
if (
    block.toolName === 'replace_file_content' ||
    block.toolName === 'multi_replace_file_content' ||
    block.toolName === 'edit_file' ||
    block.toolName === 'edit_diff' ||
    block.toolName === 'write_file' ||
    block.toolName === 'write_to_file'
) {
    const targetContent = parsedInput.targetContent ?? parsedInput.TargetContent
    const replacementContent = parsedInput.replacementContent ?? parsedInput.ReplacementContent

    if (targetContent !== undefined || replacementContent !== undefined) {
        // Single replacement (edit_file / replace_file_content)
        const target = (targetContent || '')
            .split(/\r?\n/)
            .map((l: string) => (l.startsWith('-') ? l : `-${l}`))
            .join('\n')
        const replacement = (replacementContent || '')
            .split(/\r?\n/)
            .map((l: string) => (l.startsWith('+') ? l : `+${l}`))
            .join('\n')
        displayOutput = [target, replacement].filter(Boolean).join('\n')
    } else if (parsedInput.ReplacementChunks && Array.isArray(parsedInput.ReplacementChunks)) {
        // Multi replacement (multi_replace_file_content)
        displayOutput = parsedInput.ReplacementChunks.map((chunk: any) => {
            const tContent = chunk.targetContent ?? chunk.TargetContent ?? ''
            const rContent = chunk.replacementContent ?? chunk.ReplacementContent ?? ''
            const t = tContent
                .split(/\r?\n/)
                .map((l: string) => (l.startsWith('-') ? l : `-${l}`))
                .join('\n')
            const r = rContent
                .split(/\r?\n/)
                .map((l: string) => (l.startsWith('+') ? l : `+${l}`))
                .join('\n')
            return `${t}\n${r}`
        }).join('\n')
    } else if (parsedInput.diff) {
        // Direct unified diff patch (edit_diff)
        displayOutput = parsedInput.diff
    } else if (block.toolName === 'write_file' || block.toolName === 'write_to_file') {
        // New / overwritten file (write_file / write_to_file)
        const code =
            parsedInput.codeContent ??
            parsedInput.CodeContent ??
            parsedInput.content ??
            parsedInput.code ??
            ''
        displayOutput = (code || '')
            .split(/\r?\n/)
            .map((l: string) => (l.startsWith('+') ? l : `+${l}`))
            .join('\n')
    }
}
```

## 3. End-to-End Stream Architecture (`apps/cli` & `apps/web`)

```mermaid

    participant LLM as Provider / LLM
    participant Loop as Agent Loop (packages/agent)

    participant TUI as TUI Renderer (packages/tui)
    participant Web as Web App (apps/web)

    LLM->>Loop: ToolCall(name: "edit_file", input: {path, targetContent, replacementContent})
    Loop->>Stream: Emit ToolCallStartEvent

    Loop->>Stream: Emit ToolCallResultEvent
```
